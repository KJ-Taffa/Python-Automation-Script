# Python Automation Scripts

## Overview
Collection of Python scripts for file organization, backups, and simulations.

## Scripts
- `file_organizer.py`: Scans directories, sorts files, creates timestamped backups
- `game_tournament.py`: Determines eligibility for a tournament
- `magic8ball.py`: Simulates Magic 8 Ball responses
- `ride_program.py`: Determines eligibility for a rollercoaster ride

## Technologies
- Python 3
- Libraries: argparse, os, shutil, datetime

## Usage
Run scripts from the command line:
```bash
python file_organizer.py --source /path/to/files --backup /path/to/backup
